# 买入前安全边际检查清单

**用途**：在执行任何证券买入操作前，逐项自查该笔交易是否具备真正的安全边际。每项均可回答"是/否"。若任何一项答案为"否"，应暂停买入并重新评估。

**条目**：
- [ ] 我是否能明确说出这笔投资的安全边际来源（利润覆盖倍数、资产缓冲、价格低于评估价值等），而非仅凭"感觉便宜"？（依据 p.346-347）
- [ ] 我的估值是否基于偏保守的假设，而非乐观情景下的预期利润？（依据 p.346）
- [ ] 安全边际是否经过了包含经济较差时期的多年记录检验，而非仅依赖近两三年的繁荣数据？（依据 p.345）
- [ ] 我是否避免了在经济繁荣期将当期高利润误认为持久的"盈利能力"？（依据 p.345）
- [ ] 如果这是成长股，我对未来利润的估算是否足够保守，且购买价格提供了相对于该估算的安全边际？（依据 p.346）
- [ ] 这笔投资是否纳入了足够分散的组合（20种或以上），而非集中押注于少数标的？（依据 p.344, 347）
- [ ] 我的买入决策是否基于统计数据和数学推理，而非对市场走势的主观判断或个人技能的过度自信？（依据 p.348-349）
- [ ] 我是否"知道自己在干什么"——对该证券的价值了解程度，是否等同于在经营业务时对商品价值的了解？（依据 p.352）
- [ ] 如果有可靠计算表明合理利润的机会不大，我是否会远离这笔交易？（依据 p.352）
- [ ] 我是否有勇气在数据和推理支持的情况下坚持判断，即使其他人迟疑或反对？（依据 p.353）

**原文引证**（书页 p.346）：“安全边际总是依赖于所支付的价格。如果某种价格下的安全性较大，较高价格下的安全边际就较小，价格更高时就没有了安全边际。”

**原文引证**（书页 p.353）：“获得令人满意的投资结果，比大多数人想象的要简单；获得非常好的结果，比人们所想象的要难。”

**正向案例**：在整体市场估值处于历史中位附近时买入并持有宽基指数、纳入充分分散的组合：其安全边际来自分散化与长期平均化（依据 p.344, 347），且经完整周期记录检验——逐项通过本清单。反向示例：在市场估值极端高位（CAPE 远超均值）仍全仓追买，则第 1、2、3 项不通过（参见 F-20-01 现代转译）。
