# 投资vs投机自检清单

**用途**：在执行任何证券买入操作前，逐项自查该行为是否符合投资定义，避免在无意识中滑入投机。每项均可回答"是/否"。

**条目**：
- [ ] 我是否对该证券进行了深入分析（而非仅凭感觉、消息或趋势判断）？（依据 p.13）
- [ ] 我的分析是否能合理确认本金的安全性（即损失概率可控）？（依据 p.13）
- [ ] 我预期的回报是否是适当的（与分析深度和风险水平匹配，而非追求暴利）？（依据 p.13）
- [ ] 我是否清楚自己是在投资还是在投机，且没有在思想上将二者混为一谈？（依据 p.16）
- [ ] 如果是投机，我是否使用了独立的账户且限定了我能承受全部亏损的资金量？（依据 p.16）
- [ ] 我是否避免了因市场上涨或利润激增而追加投机资金的冲动？（依据 p.16）

**原文引证**（书页 p.13）：“投资业务是以深入分析为基础，确保本金的安全，并获得适当的回报；不满足这些要求的业务就是投机。”

**原文引证**（书页 p.16）：“不要把你的投机操作与投资操作放在一个账户中进行，也不能在思想上将二者混为一谈。”
