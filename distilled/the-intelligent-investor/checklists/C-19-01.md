# 股东视角的股息政策审查清单：持仓公司低支付或不付股息时，按七问定性与处置——是合理豁免、可证明的再投资，还是压估价的疑点

**用途**：把 P-19-01（管理层结果三判据）、P-19-02（付出去或证明之）、P-19-03（股息的定价权重）、P-19-04（股票股息名实之辨）落成一张可对单只股票执行的核查表。适用情境：你持有的公司支付率明显低于惯例、零支付、或以股票股息/分割替代现金派发。逐项回答，最后按"处置项"行动。

**条目**：
- [ ] 1. 支付率是否处于通常水平（书中惯例约支付三分之二，成熟公司一般 60%～75%）？明显低于则进入后续各问；不低于则本清单可提前结束（依据 p.334、p.337）（era-bound：三分之二/60%~75% 是 1960-70 年代美国成熟企业惯例，现代转译为与同行业可比公司的支付率/总回报率——股息＋回购——中位数对照）
- [ ] 2. 留存是否有可见证明：利润再投资是否带来了每股利润的满意增长，且"这种证明通常可以从公司明显的增长率中看到"？有持续增长记录则低支付可豁免（市场也确有许可：增长记录越好越容忍低支付）；无记录则红旗（依据 p.335、p.337）
- [ ] 3. 吝啬付息是否因财务实力相对较弱、需要以全部或大部分利润（加上折旧费）偿付债务和增加营运资本？若是，"股东就没有多少话可说了"——但记入另一条批评：管理层把财务状况搞得如此难以令人满意（依据 p.337）（现代转译：看杠杆、利息保障、现金缓冲与再融资需求；财务弱势豁免的是股息质问，不豁免质量降级，衔接 C-14-01 财务稳健关）
- [ ] 4. 若公司属于"业务不太兴旺"却以扩张为名留存：要求完整解释与令人信服的理由；业绩平平且管理层未变时，没有理由相信所有者能从自己资金带来的扩张中获益——举证责任在管理层而非股东（依据 p.337）
- [ ] 5. 低支付率是否恰是平均市价低于公允价值的原因？若是，"股东完全有理由去进行调查，并且可以说出自己的不满"——这一情形下的廉价反而是研究触发器（衔接 P-15-01 被歧视股、P-20-01 安全边际）（依据 p.337）
- [ ] 6. 公司派发的股票股息/分割是否名实相符：股票股息是否有近期（如两年内）利润再投资作对应、是否按市值从盈余转入资本？达到或超过 25% 应按分割理解；与近期利润无关的"随意公布 10%"式旧做法是混乱信号（依据 p.338、p.339）（现代转译：A 股看送股与转增的权益来源与除权税制，美股看 stock dividend 的资本化会计；识别高送转市值管理噱头）
- [ ] 7. 治理兜底：对管理层能力的三判据是否已触发——结果本身差、比类似环境其他公司差、股价长期不能令人满意？若触发，客观细致地对待其他纠正性股东送来的代理材料，评估其提案与证据（依据 p.332、p.334）
- [ ] 处置项：2 无证明且 3 无豁免 → 按 5 判断是"疑点折价"（研究/不满）还是"价值毁灭"（卖出）；4、6 任一为红旗 → 降低仓位或剔除；7 触发且管理层无改变迹象 → 依 P-19-01，改变通常来自外部控制者，个人股东的最优动作是投票、卖出或等待并购纪律，而非亲自开战（依据 p.333、p.337）

**原文引证**（书页 p.337）：“我们认为，股东要么要求管理层按通常的做法支付利润（比如，大约支付三分之二），要么要求他们能够明确地证明，利润再投资使得每股利润获得了满意的增长。”

**原文引证**（书页 p.337）：“但是，在其他许多情况下，较低的股息支付率显然是平均市价低于公允价值的原因，因此在这种情况下，股东完全有理由去进行调查，并且可以说出自己的不满。”

**原文引证**（书页 p.337）：“这种情况下，股东就没有多少话可说了，或许只能批评管理层把公司的财务状况搞得如此难以令人满意。”

**原文引证**（书页 p.335）：“以往的增长记录越好，投资者和投机者就越乐意接受支付较低股息的政策。”

**原文引证**（书页 p.339）：“纽约股票交易所将股票分割和股票股息之间的实际界线确定为25%。达到或超过25%的股票股息分配，无需采用将其市值从盈余账户转到资本账户等做法。”

**原文引证**（书页 p.332）：“下列情况下股东有理由对管理层的能力产生怀疑；（1）其结果本身不能令人满意；（2）其结果比类似环境下其他公司的要差；（3）其结果导致股票价格长期不能令人满意。”

**现代转译**：清单骨架（付出去或拿出证明／财务弱势豁免／平庸者留存默认不可信／低支付致折价是调查理由／股票派发名实之辨／治理三判据）全部可用，需替换的仅是数值与规则：三分之二支付率改为同业对照；认购权与股票股息的税制账在现代美股多被回购取代，转译为"总回报率（股息＋净回购）与每股指标是否同步提升"；25% 界线以当期交易所与会计准则为准（中国对送转股数与除权、税负另有规定）。增持渠道（股息再投资 DRIP）与激进基金提案是"代理材料"项的现代接口。

**正向案例**：逐项通过的示例：持有一家支付率 55%（处于同业中位数附近）的成熟工业公司——条目 1 即结束核查；另一例为零股息但近十年 EPS 年增 15%、ROIC 持续高于 15%、现金充裕的成长公司——条目 2 给出可见证明、条目 3 无弱势，豁免成立（德州仪器形态）；反例即 Superior 石油式极端（留存有利润支撑）与 ATT/IBM 式分类摇摆（P-19-03），提示定期复核市场归类是否改变。

**关联卡**：P-19-01（三判据与治理机制来源）、P-19-02（本清单的裁决原则）、P-19-03（定价权重证据——条目 5 的依据）、P-19-04（条目 6 的原理卡）、C-14-01（条目 3 的财务稳健关完整版）、C-15-01（条目 5 判定廉价后的可买性确认）、P-05-01（防御型选股中股息记录的前置筛）、P-20-01（低支付折价与安全边际的衔接）。
