# 防御型投资组合自检清单

**用途**：在建立或审视防御型投资组合时，逐项自查是否满足格雷厄姆对保守投资者的基本要求。每项均可回答"是/否"。若任何一项答案为"否"，应重新评估组合结构。

**条目**：
- [ ] 股票投资比例是否在25%-75%范围内，且当前配置有明确理由？（依据 p.58）（era-bound：25%/75%阈值源于1970年代；现代转译：可调整为30%-70%或使用目标日期基金滑行轨道，但必须设定上下限）
- [ ] 债券部分是否全部为高等级债券（Aaa/Aa/A级或同等评级），不含低等级高收益债？（依据 p.67）
- [ ] 股票部分是否限于大型蓝筹股或宽基指数基金，而非个股投机或小盘概念股？（依据 p.58）
- [ ] 是否建立了机械化的再平衡规则（如每年一次或偏移超过5%时触发），而非依赖主观判断？（依据 p.60）（现代转译：可用5%/25%再平衡阈值、自动再平衡基金或robo-advisor替代原文"十一分之一"算法）
- [ ] 我是否能坦然面对类似1969-1970年的大幅下跌，而不会恐慌性清仓？（依据 p.59）
- [ ] 如果持有优先股，是否仅在价格跌至不合理低位时才买入，而非按面值购买？（依据 p.70）
- [ ] 长期债券是否具有足够的赎回保护期（发行20年以上不可赎回）？（依据 p.69）（era-bound：具体年限取决于当时利率环境；现代转译：关注callable bond的call protection期限及yield-to-worst）

**原文引证**（书页 p.58）：“他应当将其资金分散投资于高等级的债券和高等级的普通股。”

**原文引证**（书页 p.67）：“就普通投资者而言，规避此种高收益债券不失为明智之举。”

**正向案例**：一位防御型投资者将资产按50:50分配于宽基指数基金（如标普500 ETF）与高等级债券基金（如美国国债或AAA级公司债ETF），每年末检查一次比例，当任一类资产偏离目标超过5个百分点时执行再平衡；只买不可赎回或赎回保护期充足的债券基金；从不触碰高收益债、小盘概念股或优先股——逐项通过本清单。
