# 每股利润可靠性检验清单：把 EPS 放进估值模型之前逐项过一遍

**用途**：第12章把损害每股利润可比性的会计因素逐一列名（特殊扣除、以往亏损导致的所得税扣除下降、可转债/权证稀释、折旧方法、研发扣除时点、FIFO/LIFO），并给出修复工具（7-10年平均利润、规范的增长率口径）与最后兜底（确保物有所值）。本清单把全章压缩成买入前的操作流程：先用七项检验定位失真，再用三项核对重建可用数字，最后按"金额不大不纠缠、仍不可靠则退守物有所值"决策。

**条目**：
- [ ] **口径声明**：我用的 EPS 是哪一个？报告中存在几种口径（基本/扣除特殊费用前后/完全稀释前后），我的市盈率分子分母是否同口径？（依据 p.206-207）
- [ ] **特殊项目体检**：扣除的"特殊费用"是否为未来亏损与成本的提前计提？该企业是否年年都有"特殊项目"（多元化大企业的部门关闭、退出、重组本是正常营运）？（现代转译：逐年翻查 non-GAAP 调节表，"经常发生的一次性费用"应按经常性处理）（依据 p.207-208, p.210）
- [ ] **税收异常检查**：利润增长是否来自以往亏损造成的正常所得税扣除下降？应先按全部所得税负债反映盈利能力，再把暂时性税收减免单独折算加值（西北工业式陷阱）。（依据 p.209, p.212-213）
- [ ] **稀释核算**：可转债、优先股与权证全部行使后股数增加多少（美铝降4%，西北工业翻倍以上）？是否改用稀释后股数重算每股指标？（现代转译：以含 SBC/RSU/期权的"全在权"股数与股权总价值口径复核市值与每股利润）（依据 p.207, p.211 注, p.213）
- [ ] **会计政策变动**：本年度利润增长有多少来自折旧方法切换（Trane 案例：增长近20%，其中一半来自弃用加速折旧改回直线折旧）、研发成本扣除时点的选择、FIFO/LIFO 存货估价的差异？（依据 p.211）
- [ ] **重要性过滤**：涉及金额不大的会计变量不必纠缠，也不被华尔街的吹毛求疵带节奏（道氏公司把21美分项目计入普通利润还是特殊收益之争"何必大惊小怪"——一年的微小变化不可能影响未来平均利润或估价）；反向自查：自己是否在为噪声做交易决定？（依据 p.211-212）
- [ ] **平均利润核对**：用7-10年平均利润对照最近单年——平均数既缓和周期波动，又"几乎可以解决所有特殊费用和利益的问题"（这些损益本就是营运历史的一部分）；美铝1961-1970十年平均每股3.62美元，与头条5.20美元差距立现。（依据 p.213）
- [ ] **增长率规范口径**：计算增长率用近3年平均数与10年前的相应平均数对比，而非单年对单年（可在特殊费用问题上取得折衷）。（依据 p.214）
- [ ] **趋势与质量终检**：平均数会不会掩盖趋势转折（高成长时近期利润本就大大超出长期平均，须平均与最新并用）？该企业资本利润是否高于平均水平——"只有当企业的盈利能力高于平均水平时，才能维持较高的市盈率"；历史增长优良不代表当前价格安全（美铝1959年45倍市盈率透支之后，11.5倍仍被市场继续打到底）。（依据 p.214-216）
- [ ] **兜底纪律**：全部检查做完仍无法确定"实际利润"时，放弃精确性幻想——只在价格相对可核实的价值区间留出明显余量时买入，并这样保持下去。（依据 p.213）

**原文引证**（书页 p.211）：“投资者越是看重每股利润，就越有必要注意各种会计因素对其实际可比性的损害。我们已经提到了三种因素：使用特殊扣除——这不会在每股利润中得到反映；由于以往的亏损导致的正常所得税扣除的下降；大量可转换债券或权证带来的稀释作用。”

**原文引证**（书页 p.211）：“该公司的每股利润比1969年增长了近20%（1969年和1970年分别为2.76美元和3.29美元），但是其中一半的增长，来自于重新使用了较古老的直线折旧法——这比前一年使用的加速折旧法对利润所带来的压力更小。”

**原文引证**（书页 p.213）：“公司会计经常是需要慎重对待的；证券分析会非常复杂；股票估价只有在非常罕见的情况下，才是真正可靠的。对大多数投资者而言，最好的方法或许是，确保自己购买的证券物有所值，并且这样保持下去。”

**原文引证**（书页 p.213）：“这种平均法的一个重要优势在于，它几乎可以解决所有特殊费用和利益的问题。这些费用和利益应该包含在平均利润中。因为，毫无疑问，这些损益中的大多数都代表了企业的一部分营运历史。”

**原文引证**（书页 p.214）：“我们建议，增长率本身的计算，可以采用把近3年平均数与10年前的相应数据进行对比的做法。”

**原文引证**（书页 p.215）：“只有当企业的盈利能力高于平均水平时，才能维持较高的市盈率。”

**现代转译**：各条目今天的落地数据源：10-K/年报的 GAAP 与 non-GAAP 调节表（特殊项目、SBC 加回）、稀释加权平均股数与股本变动表（稀释、股数爬升）、有效税率与递延税资产附注（税收异常）、D&A 会计政策变更附注与 FIFO/LIFO 披露（政策变动）、席勒 CAPE 或 7-10 年平均归母净利润（平均利润核对）、ROIC vs. WACC（盈利能力终检）。清单的元规则不变：EPS 是被制造出来的数字，检验它的成本远低于检验一次错误估价的代价。

**正向案例**：一位投资者考察某发布"调整后 EPS"创新高、市盈率看似便宜的工业企业：他先核对 GAAP 稀释 EPS 与调整后口径的差距（发现剔除的"重组费"已连续第五年出现，按经常性计回）；再用全在权股数重算市值（期权在权部分使股数增加约6%）；翻查发现有效税率因往年亏损降至正常值一半，按全额税率还原；最后以近7年平均利润计算倍数仍高于其历史区间且 ROIC 平庸——虽然未能精确锁定"实际利润"，但触发了兜底条款：价格未留出明显余量，放弃买入，继续持有现金等待。逐项通过本清单。
