# 选择顾问与交割安全清单

**用途**：在委托他人执行交易或接受投资服务之前，逐条检验交易对手、保管安排、激励结构与自身角色。本章末格雷厄姆给出的是一套"宁可谨慎"的操作防线——针对的不是市场风险，而是中介风险（经纪商破产、交割漏洞、推销话术）。

**条目**：
- [ ] **资质过滤**：是否只与信誉卓著、受交易所监管的经纪商打交道？（era-bound：原文为"只与纽约股票交易所的会员打交道"；现代转译：选择受证监会持牌监管的券商与托管机构，如美国的SIPC成员公司、受FINRA监管的经纪商）（依据 p.177, p.182）
- [ ] **保管隔离**：无保证金账户的普通投资者，证券是否通过银行交割——买入时交付给付款银行，卖出时银行收款后再交付经纪商？（现代转译：资产托管与交易/建议职能分离，使用独立托管人或大券商的注册托管账户，绝不让收建议的机构同时全权持有资产）（依据 p.177）
- [ ] **佣金结构诊断**：对方的收入来自我的资产年费，还是来自我的交易佣金与产品销售？（依据 p.172, p.181）
- [ ] **预期校准**：若未为建议支付专门费用，是否已放弃"获得优于平均水平结果"的预期？（依据 p.181）
- [ ] **承诺警觉**：是否对所有承诺"惊人收益或盈利"的人保持警惕——无论是客户经纪商还是证券推销员？对捉摸不定的"市场择时技巧"是否同样不信不买？（依据 p.181）
- [ ] **亲友否决**：是否避免了向亲属或朋友寻求投资建议？（选择满意顾问与自己独立选证券几乎同样困难，"人们会随意给出许多不良的建议"）（依据 p.180）
- [ ] **角色明确**：防御型投资者能否明确（甚至不断重复）地说出自己打算买哪几种证券（高等级债券+价格不高的著名公司普通股），把顾问用作执行与信息支持而非决策外包？积极型投资者是否坚持要求顾问详细解释建议、并表达自己的独立判断？（依据 p.181-182）
- [ ] **盲从例外条款**：只有在顾问的品德与能力被反复证明完全可靠这一罕见情况下，是否才允许自己在未理解、未认可决策依据时照建议下单？（依据 p.182）

**原文引证**（书页 p.177）：“我们认为，没有保证金账户的人（在我们看来，这些都是非职业投资者），应该通过其银行进行证券的交割。”

**原文引证**（书页 p.180）：“选择一个满意的普通顾问，与自己独立地选择恰当的证券几乎是一样困难。”

**原文引证**（书页 p.181）：“他们应该对所有的人保持警觉，无论是客户经纪商，还是证券推销员（他们将承诺有惊人的收益或盈利）。”

**原文引证**（书页 p.182）：“最好注意安全，免得到时后悔。”

**现代转译**：本清单的"通过银行交割"条目源于1969-1970年纽约经纪商破产潮（部分经纪公司拿自有资本投机、客户资产安全规则失效）。现代制度环境已大幅改善——客户资产分离存管、SIPC每人50万美元保障、DTC集中交割——但风险形态只是转移而非消失：独立投顾挪用客户资产（庞氏骗局式丑闻）、互联网券商后台故障、无牌照"荐股群"与场外配资仍周期性出现。清单的实质操作今天应读作：核查牌照与监管记录（如SEC/FINRA的BrokerCheck、中国证券投资基金业协会公示）、确认托管方独立于建议方、拒绝收益承诺、把"付费方式"当作利益冲突的第一信号。

**正向案例**：一位退休前投资者：通过监管网站核查了投顾机构的注册与处罚记录，选择按资产规模收取固定年费（fee-only）的注册投顾；账户开立在与该投顾无关联的第三方托管券商处，定期对账单由托管方直接发出；对顾问推荐的任何"保证年化15%的策略"一律拒绝；自己始终能说清每笔持仓属于高等级债券或价格合理的知名公司股——逐项通过本清单。
