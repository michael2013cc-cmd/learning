# 我是否适合做进取型投资者

**用途**：与C-01-02（防御型vs进取型自我定位清单）互补，本清单专门检验你是否具备做进取型投资者的实际条件。通过全部条目才应考虑积极型策略；任一否定即应回归防御型框架。四个维度：时间、技能、纪律、情绪。

**条目**：
- [ ] **时间维度**：我是否每周能投入足够时间进行证券研究、财务分析和持仓监控，且这种投入可以持续数年而非一时热情？（依据 p.118）
- [ ] **技能维度**：我是否掌握了证券估价的专业知识（包括利润分析、资产估值、行业比较），足以将投资“看成一种事业”而非凭感觉操作？（依据 p.118）
- [ ] **纪律维度**：我的投资策略是否具有内在稳健性且在华尔街并不流行？我能否在策略暂时跑输时坚持执行而不频繁更换方法？（依据 p.105）
- [ ] **情绪维度**：我能否承受短期内大幅跑输市场的心理压力，不因嫉妒他人收益而偏离既定策略去追逐热门？（依据 p.119）
- [ ] **预期校准**：我是否理解进取型的首要目标是“不收获比防御型更差的结果”，然后才是争取更好？我对超额回报的预期是否建立在技能和努力之上，而非运气或热情？（依据 p.119）

**原文引证**（书页 p.118）：“积极投资者必须拥有大量的证券估价知识，才能把自己的证券业务看成一种事业。”

**原文引证**（书页 p.119）：“他们应该满足于现在从防御型证券组合中获得的优越回报（甚至是较低的回报）；而且，他们还应该坚定地抵制不断出现的诱惑——为了增加回报，而偏离到其他道路上去的诱惑。”

**正向案例**：一位具有会计背景的专业人士，每周固定投入10小时研究财报和行业数据，采用“不受欢迎的大公司低市盈率+净流动资产折价”双因子策略，连续三年在市场下跌年份跑赢指数、上涨年份略逊但总体复合回报优于宽基——逐项通过本清单，且其超额回报可归因于系统化分析而非择时运气。
