# 防御型选股自检清单

**用途**：在挑选或审视防御型普通股组合中的每一只股票时，逐项检查是否满足格雷厄姆的质量与估值门槛。任何一项答案为"否"的股票应被排除或替换。此清单不适用于进取型投资者的主动选股策略。

**条目**：
- [ ] 持股数量是否在10至30只之间，实现适度分散？（依据 p.74）（现代转译：若使用宽基指数基金替代个股，此条自动满足；若选个股，上限30只为防止过度分散导致管理失控）
- [ ] 该公司是否为行业龙头或主要指数成分股，规模处于所在行业前四分之一？（依据 p.75）（era-bound：原文以资产/营收5000万美元为下限；现代转译：可参照标普500成分股资格或行业中位数市值以上）
- [ ] 公司财务是否稳健——工业企业账面价值不低于总资本的一半，公用事业/铁路不低于30%？（依据 p.83）（era-bound：具体负债率阈值源于1970年代资本结构；现代转译：关注净债务/EBITDA低于2倍、利息覆盖率高于5倍等当代偿债能力指标）
- [ ] 是否具有长期连续支付股息的历史（至少20年以上未中断）？（依据 p.75）（era-bound：原文要求从1950年起连续分红；现代转译：连续10年以上稳定分红且未大幅削减即可视为合格，或使用高股息指数基金替代）
- [ ] 当前市盈率是否在过去7年平均利润的25倍以内，且在最近12个月利润的20倍以内？（依据 p.75）（era-bound：25/20倍阈值反映1970年代估值中枢；现代转译：可参照标普500历史CAPE中位数约16-18倍作为锚点，允许合理上浮但不追高估值极端值）
- [ ] 该股票是否不属于"热门成长股"——即估值未透支未来多年增长预期？（依据 p.76）
- [ ] 买入价格相对于内在价值是否存在安全边际，而非仅因"看起来便宜"而买入？（依据 p.83）

**原文引证**（书页 p.74）：“适当但不要过分的分散化，你的持股数应限制在最少10只，最多30只不同的股票之间。”

**原文引证**（书页 p.75）：”投资者应将其买入股票的价格限制在一定的市盈率范围，其参照的每股利润，应取过去7年的平均数。我们认为，针对这一平均数，其市盈率应控制在25倍以内；如果是过去12个月的利润，则应控制在20倍以内。”

**正向案例**：一位防御型投资者选择了一只跟踪标普500高股息指数的ETF作为核心持仓：该指数成分股均为大型知名公司、连续10年以上稳定分红、加权平均市盈率约16倍（低于历史中位数）、财务杠杆处于行业中位水平。该投资者不持有个股，但通过指数基金的筛选机制逐项满足了本清单的质量门槛；每年检视一次指数编制规则是否仍符合标准，若指数纳入过多高估值或财务恶化公司则考虑更换标的——逐项通过本清单。
