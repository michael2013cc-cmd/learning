# 防御型vs进取型投资者自我定位清单

**用途**：帮助投资者诚实评估自己属于防御型还是进取型，从而选择与之匹配的策略框架。错误定位是投资失败的常见根源。

**条目**：
- [ ] 我是否愿意每周投入至少数小时进行证券研究和财务分析？若否，应定位为防御型。（依据 p.17）
- [ ] 我是否有足够的知识和技能来分析个别证券的价值，而非仅依赖市场情绪或他人推荐？若否，应定位为防御型。（依据 p.24）
- [ ] 我能否承受短期内跑输市场的心理压力而不改变既定策略？若否，需重新审视定位。（依据 p.24）
- [ ] 如果我自认进取型，我的策略是否具有内在稳健性且在华尔街并不流行？（依据 p.26）
- [ ] 我是否已做好准备：进取型的首要目标是不收获比防御型更差的结果，然后才是争取更好？（依据 p.24）

**原文引证**（书页 p.16）：“我们已经将防御型投资者定义为关心资金安全同时又不想多花时间和精力的人。”

**原文引证**（书页 p.24）：“我们的激进型投资者当然会期望自己取得比防御型或被动型投资者更好的收益。但是，他必须首先确定，自己不会收获更糟的结果。”

**正向案例**：一位全职工作者确认自己无意愿、无时间做个股深入研究，诚实定位为防御型，选择"宽基指数定投+年度再平衡"的系统化方法，并把少量投机资金隔离在独立账户——逐项通过本清单（参见 P-08-05、F-08-01）。
