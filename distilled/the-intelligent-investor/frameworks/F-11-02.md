# 两步评估法：先锚定"以往业绩的价值"，再做预期修正

**步骤**：

1. **计算"以往业绩的价值"作为锚**（依据 p.202-203）：完全取决于过去记录——假设其以往的相关业绩（绝对值，或以道指/标普的相对百分比表示）将在未来持续，且相关增长率（如过去7年的增长率）在随后7年中保持不变；这一步可按部就班：用一个公式，对过去的盈利能力、稳定性、增长率以及目前财务状况等数据赋权求值。（现代转译：即"基准情形=过去延续"的规则化估值，对应现代的量化因子估值锚或DCF的零增量基础情形；7年窗口与权重设计不必照搬，关键是锚必须只由可核实的过去数据构成，不含观点）

2. **按未来预期做显式修正**（依据 p.203）：第二步只回答一个问题——完全以以往业绩为基础的价值，应该根据未来预期的新情况进行多大程度的修正；修正必须写明方向、幅度与理由。

3. **分工与留痕**（依据 p.203）：高级分析师负责确定适用于所有公司的一般化公式（锚）与修正原则，初级分析师以简单方式算出特定公司各因素的价值；最好的报告同时呈现初始价值、修正后价值以及调整理由——把"数据"与"观点"分开入账。

4. **限定适用范围**（依据 p.204）：聪明的分析师把自己的工作限于两类对象——其未来似乎可以合理做出预测的行业群体；或者以往业绩的价值相对于当期价格的安全性很大，大到可以对未来变化做推测（"正如他在挑选十分稳妥的优先证券时那样"）。（现代转译：即只在"可预测性高"或"价格相对历史价值锚折价足够深"两处下注，与第11章末尾对公用事业股等稳定行业的肯定相呼应，也是安全边际（P-20-01）在分析流程上的落地）

**原文引证**（书页 p.203）：“我们所说的“以往业绩的价值”，这完全取决于过去的记录。这将反映股票的价值状况（绝对状况，或者是道琼斯工业平均指数或标准普尔综合指数的百分比）——如果假设其以往的相关业绩将在未来持续下去的话。”

**原文引证**（书页 p.203）：“这一过程可以按部就班进行：使用一个公式，计算出以过去的盈利能力、稳定性、增长率以及目前财务状况等数据为基础的各个权重；分析的第二步要考虑，完全以以往业绩为基础的价值，应该根据未来预期的新情况进行多大程度的修正。”

**原文引证**（书页 p.204）：“最终，聪明的分析师将使自己的工作限于下列行业群体：其未来似乎可以合理地做出预测；或者是以往业绩的价值相对于当期价格的安全性很大，因此他可以对未来的变化做出推测，正如他在挑选十分稳妥的优先证券时那样。”

**现代转译**：本框架的精髓是给不可靠的未来预测装一个"可审计的起点"：先用纯历史数据规则化算出基准价值，再把所有前瞻性判断压缩成第二步的显式调整项。这正是现代估值实践中被反复验证的秩序——量化因子模型定锚、基本面观点只做有限调整；对普通投资者的简化版是：以过去7-10年平均盈利与平均财务指标算一个"历史价值区间"，只有当市价显著低于该区间、且自己不依赖任何乐观未来故事时才买入。

**时代受限项**：步骤1中以道琼斯工业平均指数或标普综合指数为相对基准（现代转译：改用本国宽基指数或直接以绝对美元价值为基准）；步骤1的"过去7年增长率延续7年"的时间对称假设（现代转译：延续期应按行业可预测性设定，稳定业种可长、技术变革快的业种应短甚至放弃）；格雷厄姆自己承认"我们不知道，对一般的工业企业而言，这样估算出的价值是否足够可靠"（p.203），故该框架须与保守性纪律（P-11-01）配套使用，其可靠性验证见下一章美国铝业案例。
