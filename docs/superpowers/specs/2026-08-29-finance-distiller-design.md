# 金融著作蒸馏系统设计文档

- 日期：2026-08-29
- 状态：已批准（待实现计划）
- 首个工件：《聪明的投资者》（原本第 4 版，中文译本）

## 1. 背景与目标

用户希望把经典金融著作总结、蒸馏为可复用的知识资产，最终形成一个"会造 skill 的工具"（元工厂）。经需求澄清，确定三用途并行：

1. **知识库检索问答**：结构化存入 QMind，支持语义检索与跨书问答
2. **决策顾问**：生成可调用的"格雷厄姆顾问 skill"，覆盖四个场景——个股/标的分析、决策对照检查、作者视角问答、持仓反思报告
3. **元工厂**：管线本身沉淀为可复用的 `book-distiller` skill

范围决策：**先跑通这一本**（样章验证后再推全书），源材料需**兼容扫描版与文字版**，蒸馏风格为**分层混合式**（核心原则严格引证，应用层允许重构）。

## 2. 调研结论

### 2.1 本书公认核心观点

- 投资与投机的严格区分（第 1 章）：彻底分析 + 本金安全 + 满意回报
- Mr. Market（第 8 章）：市场是仆人不是主人，波动是机会不是指示
- 安全边际（第 20 章）：买价低于价值，为错误留缓冲。巴菲特称第 8、20 章为"有史以来最好的投资文字"
- 防御型/进取型投资者（按努力程度分类）
- "投资者最大的敌人是他自己"——本质是投资心理学著作
- 股债 25%-75% 动态再平衡（第 4 章）

### 2.2 严肃批评（驱动设计的关键约束）

- 具体量化标准（市盈率阈值、股息率、债券规则）是 1960-70 年代美国市场产物，直接套用今天市场不适用；但"构建指标体系的思维方式历久弥新"
- 格雷厄姆式纯量化筛选在现代市场难有合格标的
- 刻意排斥定性分析（护城河、管理层质量），与巴菲特/费雪流派存在明确分界
- 大部分章节现代读者不必通读（巴菲特式读法直奔第 8、20 章）

→ 设计回应：**现代性标注**（每条原则标注时效）、**顾问自知之明条款**（能力边界、流派差异、"本书未讨论"声明）。

### 2.3 已有先例

GitHub 开源 `grahamben-skill`（格雷厄姆视角 persona skill）：人物/哲学/方法论/风格/禁止事项结构可借鉴，但其知识硬编码、无原书引证——我们的 skill 以蒸馏卡片为 grounding，引证可回溯。

## 4. 路线与推进节奏

选定**路线 2：样章先行、管线随行**。

```
[源文件] → ① Ingest 读取层 → ② Distill 蒸馏层 → ③ Output 产出层 → ④ Meta 沉淀
```

| 阶段 | 内容 | 产出 | 质量门 |
|---|---|---|---|
| P1 样章验证 | 第 1/8/20 章手工深蒸馏，打磨模板 | 蒸馏 schema 定稿 + 测试集通过 | 用户确认 |
| P2 全书推进 | 管线跑完全书，入库，生成顾问 skill | 完整知识库 + `graham-advisor` | 用户确认 |
| P3 元工厂 | 流程/模板/脚本固化为 skill | `book-distiller` 元 skill | 换书泛化验证 |

每阶段结束设人工质量门，不自动推进。

## 5. 架构设计

### 5.1 Ingest 读取层

- 输入适配：扫描 PDF（本例）与文字版（epub/txt/md，后续书）
- 扫描路径：PyMuPDF 渲染页面 → OCR（tesseract `chi_sim`，质量已验证优秀）→ 抽检不合格时视觉模型逐页兜底
- 输出：`ingest/<book>/chapters/ch-NN.md`（章节化文本）+ `page-map.md`（章节↔书页↔PDF 页映射）
- 进度可断点续跑（按章保存）

### 5.2 Distill 蒸馏层（分层混合式 schema）

每本书产出 `distilled/<book>/`：

- `book.json`：元数据（书名、作者、版本、译者、ISBN、底本、蒸馏日期、语言）
- `chapter-map.md`：章节结构与页码映射
- `principles/`：**核心原则层（严格引证）**。每卡：原则陈述 + 原文引用（中译）+ 章节&书页定位 + 重要性分级 + **现代性标注**（永恒 / 时代受限 / 需现代转译 + 转译说明）
- `models/`：思维模型层。Mr. Market、安全边际、防御/进取型、投资者自我管理等：定义、适用场景、常见误用
- `checklists/`：应用层（允许重构）。决策检查清单（投资vs投机、选股标准、仓位规则）
- `frameworks/`：应用层。分析框架（财务稳健性检查、估值方法）
- `preface-appendices/`：巴菲特序 + 附录蒸馏（本版的"现代视角"素材来源）

铁律：**无引证不立卡**。蒸馏方式：逐章用固定提示模板蒸馏 → 跨章去重整合。

### 5.3 Output 产出层

**A. QMind 知识库**
- Notebook「金融经典蒸馏」；导入粒度 = 每卡一文档（语义检索命中卡片级）
- 每文档带元信息：书名、章节、页码、时效标签
- 天然支持后续跨书问答

**B. `graham-advisor` skill**

```
skills/graham-advisor/
  SKILL.md          # 人格 + 子命令 + 防幻觉条款
  references/       # 蒸馏产物摘要与索引
```

四个子命令：

| 命令 | 场景 | 关键规则 |
|---|---|---|
| `/graham-analyze <标的>` | 个股/标的分析：财务稳健性→估值→安全边际 | 财务数据由用户提供或网络查询（MVP 不建数据接口）；时代受限标准附现代转译 |
| `/graham-check <决策>` | 决策对照检查 | 输出对照结果 + 原书引证 |
| `/graham-ask <问题>` | 作者视角问答 | 先检索 QMind；引证带章节页码；无依据明说"本书未讨论" |
| `/graham-review <持仓>` | 持仓反思报告 | 侧重"投资者最大的敌人是自己"维度 |

防幻觉三条款：事实主张必须出自蒸馏卡片并带引证；"书中观点"与"现代转译"显式分离；不做短期价格预测。
自知之明条款：明确格雷厄姆方法能力边界、与巴菲特/费雪流派差异。

### 5.4 Meta 沉淀层

`book-distiller` skill（P3）：参数化 schema 模板 + Ingest/Distill/Output 流程，输入（书文件 + 语言 + 类型）→ 产出知识库 + 对应顾问 skill。兼容扫描版/文字版。

## 6. 质量门与验收

- **P1 样章门**：8 题测试集（3 事实检索 + 3 作者视角 + 2 决策对照），存 `tests/question-set.md`。通过标准：引证 100% 可在原文定位、时效标注正确、用户主观认可。同步完成 OCR 抽检。
- **P2 全书门**：全书入库；四个顾问场景各跑一个真实案例；随机抽 10 张卡片验引证。
- **P3 元 skill 门**：换一本新书（或其一章）跑 `book-distiller` 验证泛化。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 中文 OCR 误识 | 样章抽检；视觉模型兜底 |
| 蒸馏幻觉 | 引证铁律 + 各质量门人工抽检 |
| 全书蒸馏长任务 | 按章分批、断点续跑 |
| 时代标准误用 | 现代性标注 + 顾问转译规则 |
