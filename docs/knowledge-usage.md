# 知识使用指南：这些蒸馏卡片什么时候用、怎么用

> 本文回答三个问题：**98 张卡分别是什么性质的知识？在什么时刻、什么场景调用？调用时遵守什么规则？**
> 使用入口：[`distilled/the-intelligent-investor/INDEX.md`](../distilled/the-intelligent-investor/INDEX.md)

---

## 1. 先分清：四类卡是四种不同的认知工具

98 张卡不是均匀的"知识点"，四类卡对应**四种不同的认知动作**，在决策过程的不同环节介入：

| 卡型 | 本质 | 你对它做的动作 | 介入时刻 |
|---|---|---|---|
| **原则卡** P（62 张） | 论断 + 依据 + 常见误读 | **核对**：验证一个观点/做法是否符合原书 | 论证时、起疑时、复盘时 |
| **模型卡** M（10 张） | 思维透镜 | **换框**：用另一个视角重新看当前处境 | 情绪波动、信息混乱、定价困惑时 |
| **清单卡** C（14 张） | 行动闸门 | **逐项放行/否决**：任何一项不过就停 | **即将执行之前**（离操作最近） |
| **框架卡** F（12 张） | 操作流程 | **照着走**：从第 1 步走到最后一步 | 接到一项分析任务时 |

一句话记忆：**清单和框架管"事前"，原则管"事中事后"，模型管"情绪时刻"**。

每张卡还有两个必须先看的元数据：

- **importance**：core（优先用）> important > minor（背景知识）。
- **modernity**（现代性）——决定这张卡**能不能直接用**，见第 4 节。

## 2. 检索路径：从问题到原书的三条路

```
路 A（最常用）  有具体问题 → INDEX.md 主题索引（17 个场景）→ 卡 id → 卡正文 → 书页页码回溯原书
路 B            系统学习   → INDEX.md 主索引按卡型通读，或按 chapter/pages 回到对应章节
路 C（规划中）  语义检索   → 每卡一文档入 QMind 知识库，自然语言直接问（P2c）
```

主题索引的 17 个场景即"真实问答场景"，例如：
`面对市场波动的态度`、`买入决策与安全边际`、`财务造假与崩溃前兆`、`利润质量与财务数字可靠性`、`投资顾问与外部建议的使用`、`业绩测量与管理人评价`。

## 3. 场景手册：典型时刻调用哪些卡

以下组合均取自主题索引的真实聚合，按投资决策生命周期排列。

### 事前——做出决策之前（清单卡 + 框架卡的主场）

| 场景 | 调用组合 | 用法 |
|---|---|---|
| **要买一只股票** | C-20-01 → F-20-01 → P-20-01/02/03 | 先过"买入前安全边际清单"10 项自查；任何一项答"否"即停；通过后再走 F-20-01 估值六步算安全边际 |
| **防御型选股** | C-01-02（先定位自己）→ C-14-01 七道筛子 → F-14-01 行业适配 | 顺序不可反：先确认自己是防御型，再选股 |
| **想做积极型投资** | C-07-01 → P-06-01 → C-15-01 / F-15-01 / F-15-02 | 先问"是否愿意持续努力"，再选烟蒂股/特殊情况框架 |
| **听消息想重仓** | C-01-01 → P-01-03 → C-20-01 | 投资vs投机自检逐项对照；投机资金必须与投资账户分离 |
| **市盈率很低，心动** | P-17-02（低 PE 是警报不是证明）→ C-12-01（EPS 可靠性）→ C-17-01（崩溃红旗） | 三张卡强制串行：先审计分母，再谈便宜 |
| **选基金 / 用顾问** | P-09-01/02 + P-10-01/02/03 + M-10-01 + C-10-01 | 渠道-激励模型判断建议来源偏向，再用交割安全清单 |
| **财报数字很漂亮** | C-12-01 + P-12-01/02/03 | EPS 是口径选择不是事实 → 逐项检验可靠性 |

### 事中——持有期间、市场剧烈波动时（模型卡 + 原则卡的主场）

| 场景 | 调用组合 | 用法 |
|---|---|---|
| **大跌，想清仓** | M-08-01（市场先生）+ P-08-01/02/03 + F-08-01 + P-05-02 | 市场先生是仆人：报价是机会不是指示；风险是永久损失而非波动 |
| **大涨，怕踏空想追** | M-08-01 + P-08-04（流行方法必然失效）+ P-14-01（拒绝为质量付高价） | 同一透镜反向使用 |
| **纠结要不要择时** | P-08-02 + P-08-05 + F-08-01 | 原书立场：不预测；合理价格下持续投资 |

### 定期——纪律性时点（季度/年度）

| 场景 | 调用组合 |
|---|---|
| 组合再平衡 | P-04-01（25%-75% 动态配比）+ P-04-02（再平衡是纪律不是预测）+ F-04-01 + C-04-01 |
| 年度自我体检 | C-01-02 + 主题索引"投资者自我定位与预期"整组 + P-04-03（优先不做错事） |
| 持仓复盘 | 对每笔操作回查对应原则卡的**常见误读**字段——这是复盘时最值钱的部分 |

### 学习与写作场景

- **引用原书观点**：所有卡的引证自带书页页码，可直接作引用来源（书页而非 PDF 页）。
- **验证别人的说法**："格雷厄姆说过 X"——先查对应主题的原则卡，对照"常见误读"字段；查无此卡即原书无此论。
- **思想史研究**：era-bound 卡 + 页码是现成的"1960-70 年代量化标准"素材库。

## 4. 使用规则与红线（防幻觉设计的使用侧）

### 4.1 modernity 是使用前的过滤器

| 标注 | 含义 | 使用方式 |
|---|---|---|
| `timeless` | 跨时代成立（安全边际、市场先生） | 可直接作为判断依据 |
| `needs-translation` | 框架成立、数值过时 | **必须连"现代转译"段一起读**，用转译后的规则（如 F-20-01 的 ERP 替代固定利差） |
| `era-bound` | 数值依赖 1960-70 年代美国市场 | 数值禁用；只作方法论与思想史参考 |

注意粒度：框架卡每个步骤、清单卡每个条目可能**单独**标注时效。用 C-14-01 这类清单时，要逐条看行内 `（era-bound：…）`/`（现代转译：…）`，不能整卡一刀切。

### 4.2 三条硬红线

1. **引证可回溯**：任何基于卡片的结论，都要能指回卡片 → 书页。给不出页码的"格雷厄姆观点"不说。
2. **"本书未讨论"边界**：格雷厄姆刻意排斥定性分析（护城河、管理层质量）。这些话题没有卡片覆盖，**不得借原书之名作答**，明说"本书未讨论"。
3. **书中观点与现代转译显式分离**：回答/写作时两节分开，不混写——读者必须知道哪句是 1973 年的格雷厄姆，哪句是转译。

另有一条能力边界（自知之明条款）：格雷厄姆体系与巴菲特/费雪流派有明确分界，涉及流派外问题时注明视角局限；医疗/法律/税务等非投资问题不在本库射程内。

### 4.3 质量基准（trust but verify）

- 引证校验：`python scripts/validate_citations.py` → `all citations verified`（98 卡全部引文可逐字定位）
- 8 题质量门测试集：`tests/question-set.md`（3 事实检索 + 3 作者视角 + 2 决策对照）
- 每章 OCR 视觉校正记录：`docs/p1-notes.md`

## 5. Agent 化使用（P2c 规划，回答样式已定稿）

### 5.1 graham-advisor skill

四个子命令：`ask`（作者视角问答）/ `check`(决策对照) / `explain`（概念解释）/ `compare`（书中观点 vs 现代转译）。

**固定四层回答结构**：
1. **清单对照**——相关 checklist 卡逐条对照用户决策，打 ✅/❌
2. **逐条引证**——每条判断附"原文引证"+ 书页页码
3. **书中观点 / 现代转译**两节显式分离
4. **明确结论**——直说格雷厄姆会怎么判断，不含糊

### 5.2 知识库入库映射（QMind）

- 粒度：**每卡一文档**，语义检索命中即卡片级
- title 规范：`II-<卡id> <卡H1>`（如 `II-P-01-01 投资的三要素定义`）
- content：卡全文**含 frontmatter**——命中后直接拿到页码、引证、现代性，无需二次解析
- 入库后用 `tests/question-set.md` 抽 3-5 题做 retrieve 验证

## 6. 一页速查

```
要动手了？        → 先查清单卡（C-）：逐项过，一项不过就停
要做分析了？      → 走框架卡（F-）：照步骤走，注意步骤级时效标注
要下判断了？      → 对原则卡（P-）：核对论断与"常见误读"
心乱了？          → 用模型卡（M-）：市场先生、双重身份、渠道-激励……
拿不准时效？      → 看 modernity：era-bound 数值禁用，needs-translation 读转译段
找不到卡？        → 主题索引 17 个场景；仍无 → 大概率"本书未讨论"，明说
```
